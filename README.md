# AisleEye (MVP)

Ego-centric tray table state classifier for aircraft cabin turnaround.

Dataset: 300 custom first-person images (100 per class) of tray-table states.
Data is kept locally and not included in this repository.

## Classes
- Upright_Locked
- Deployed_Clean
- Deployed_Hazard
